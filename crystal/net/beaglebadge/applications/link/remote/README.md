# Remote

Control a Supercon badge running our Crystal firmware (network mode on). Pick it, then choose an action:
screens (nametag, portrait, sketch, life, snake, pong, link), Menu +/-, A/B taps, the colour render, panel
clean, nametag text (UP/DOWN letter, LEFT/RIGHT move, `|` = second line, SELECT sends), or **draw**: the
joystick moves the pen on a small copy of its Sketch canvas and the strokes are sent about once a second
(one e-paper refresh each). The badge's reply (ok / refused / busy) shows at the bottom.
