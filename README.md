# Badge art

Artwork for the Supercon 2026 Billboard Badge e-paper (960x672, black/white/red).

- `reference/jason-portrait-448.jpg`: reference portrait supplied by Jason Kridner, to be rendered as a 3-color badge image with BeagleBoard.org branding.
- `out/`: finished renderings (palette PNGs using only #FFFFFF, #000000, #FF0000).
